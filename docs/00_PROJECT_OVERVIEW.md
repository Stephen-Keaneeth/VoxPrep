# VOXPREP — AI-Powered Voice Interview & Communication Platform
## Project Overview Document

> **Main Theme:** Voice AI  
> **Team Size:** 2 members  
> **Active Build Hours:** 8–12 hours (MVP sprint)  
> **Version:** 1.0 — MVP Scope

---

## 🎯 Problem Statement

Students and job seekers struggle with:
- Technical & HR interview preparation
- Expressing thoughts confidently under pressure
- Communication skills (fluency, vocabulary, structure)
- Getting realistic, adaptive, real-time feedback

Existing tools provide static questions and generic feedback — not personalized, voice-first, adaptive practice.

---

## 💡 Solution: VOXPREP

An AI-powered **voice-first** platform with two core agents:

| Agent | Name | Role |
|---|---|---|
| **Agent 1** | AI Interviewer | Conducts realistic mock interviews across Technical, HR, Situational, and Resume-based categories |
| **Agent 2** | AI Communication Coach | Provides conversational English practice, vocabulary, fluency, and answer structuring training |

## ⚠️ Core Constraints

- **Voice-first:** All primary interactions must be voice-driven
- **MVP first:** Build only what is listed in `04_MVP_vs_EXTRA.md` as MVP
- **Phase gates:** No phase starts unless the previous phase passes acceptance criteria
- **No scope creep:** Agents (AI and human) must check `07_GUARDRAILS.md` before adding any feature
